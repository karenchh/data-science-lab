Mexican Real Estate Market Analysis

This project explores the Mexican real estate market through exploratory data analysis (EDA) using Python and Pandas.

The analysis investigates property prices, property sizes, price per square metre, and differences across Mexican states and property types. It uses statistical techniques and visualisations to identify pricing patterns, examine correlations, detect outliers, and understand how location and property characteristics influence real estate prices.

Key Areas of Analysis

Data cleaning and preparation

Exploratory data analysis and descriptive statistics

Property price distributions and outlier detection

Correlation analysis between property size and price

Feature engineering: calculating price per square metre

Grouped analysis by state and property type

Variance analysis to investigate differences in property prices

Tools & Technologies

Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook

Objective

To investigate the factors associated with property prices in Mexico and understand how location, property size, and property type contribute to differences in the real estate market.

Project developed as part of the WorldQuant University (WQU) Data Science Lab.
